Comparison Table: Inline vs Internal vs External CSS

Method Where is it written? Pros Cons Best used when...
Inline CSS Inside the HTML tag (style="...") Very quick for one change
Overrides other styles		 Hard to maintain
Makes HTML messy
Cannot reuse styles		 One-time small fix or testing
Internal CSS Inside <style> tag in <head> Keeps everything in one file
Easy for small pages
Can reuse styles on the page		 Still mixes HTML & CSS
Not reusable across multiple pages		 Small single-page projects or quick prototypes
External CSS In a separate .css file (linked with <link>) Clean HTML
Reusable across many pages
Easy to maintain & update
Best for large websites		 Needs extra file
One more HTTP request (tiny delay)		 Real websites, multiple pages, teams working together
